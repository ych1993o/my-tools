响应时间

我们非常重视每一封用户来信。一般情况下，我们会在 1-2 个工作日内回复您的邮件。如果遇到周末或法定节假日，回复时间可能会顺延至下一个工作日。

对于以下情况，我们会尽量优先处理并加快回复速度：

  • 严重 Bug 报告：影响工具核心功能正常使用的问题，例如工具无法加载、结果输出错误、页面崩溃等。
  • 安全漏洞报告：涉及网站安全或用户数据安全的潜在风险，我们将第一时间核实并修复。
  • 合作洽谈：来自企业或机构的技术合作、资源置换等正式商务合作。

普通的功能建议、使用咨询等，我们将按照收件顺序依次回复，请您耐心等待。若超过 3 个工作日仍未收到回复，请检查您的邮箱垃圾邮件文件夹，或重新发送一封邮件提醒我们。

Bug 报告指南

如果您在使用我们的工具时遇到异常或错误，欢迎提交 Bug 报告。一份清晰、完整的 Bug 报告能够帮助我们更快地定位和修复问题。请在邮件中尽量包含以下信息：

  • 工具名称：您遇到问题的具体工具，例如「JSON 格式化工具」或「Base64 编解码工具」。
  • 操作步骤：详细描述您做了哪些操作，最好能一步步复现问题。
  • 预期结果：您认为工具应该输出什么样的正确结果。
  • 实际结果：工具实际给出的结果或出现的错误提示，如有报错截图请一并附上。
  • 环境信息：您使用的浏览器及版本（如 Chrome 126）、操作系统（如 Windows 11、macOS 14）以及设备类型（桌面端 / 移动端）。
  • 输入数据：如方便，请提供触发问题的输入数据片段（请勿包含敏感或隐私信息）。

收到您的 Bug 报告后，我们会进行复现和排查，并在修复后通过邮件通知您。我们承诺对所有用户反馈严格保密，不会公开您的个人信息或报告内容。对于确认的 Bug，我们通常会根据严重程度在数个工作日内发布修复版本。

常见问题（FAQ）

在联系我们之前，您也可以先查看以下常见问题，或许能立即找到答案：

  • 问：在线工具箱的工具是免费的吗？
    答：是的，我们提供的所有工具完全免费，无需注册账号，也无需安装任何软件，打开网页即可使用。
  • 问：我输入的数据会被上传到服务器吗？
    答：不会。所有工具均在您的浏览器本地运行，输入的数据不会离开您的设备，最大程度保障您的隐私安全。
  • 问：工具支持手机浏览器吗？
    答：支持。我们的工具基于 HTML5 和 JavaScript 开发，兼容主流移动端浏览器，您可以随时随地在手机上使用。
  • 问：能否离线使用这些工具？
    答：工具本身基于前端技术实现，但首次打开需要联网加载页面资源。建议您在联网状态下访问，加载完成后大部分操作可离线完成。
  • 问：密码生成器生成的密码安全吗？
    答：我们的密码生成器使用浏览器提供的加密级随机数生成器（Crypto API），生成的密码具有足够的随机性和强度，请妥善保存。
  • 问：网站会添加新工具吗？
    答：会的。我们计划持续扩展工具集合，如果您有希望增加的工具，欢迎通过邮件告诉我们。
  • 问：如何反馈功能建议？
    答：请将您的建议发送至 contact@qiushanzoudaokou.top，我们会在评估后纳入后续开发计划。
